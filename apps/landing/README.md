# Landing page

Marketing page and demo for Celia, an onchain claim verification and evidence service. Built with Astro, GSAP and Lenis. No auth, database or payments.

The product name lives in one place: `name` in [src/data/site.ts](src/data/site.ts). Section copy lives in [src/data/home.ts](src/data/home.ts).

## Run locally

```bash
npm install
npm run dev     # http://localhost:4321
npm run build
```
